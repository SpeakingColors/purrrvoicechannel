Purrr Voice Channel

A tube channel strip in the style of the ART Voice Channel: tube preamp, expander/gate, compressor/limiter, de-esser and 4 band EQ. Free and open source, by Studio 87.

Status: v0.1.0 test build. Download the zip (Windows installer, macOS installer, Linux Flatpak and VST3, PDF manual; works offline) or see the release page. Not yet checked in a real DAW. The plugin window and sound are this mockup. The manual (PDF) has install steps and a tour of every control.

Below is the playable mockup (the plugin looks and sounds the same): press Play, switch tubes, turn Gain, Voicing and Colour. Open it full screen · Source on GitHub · Support Studio 87 on Ko-fi
